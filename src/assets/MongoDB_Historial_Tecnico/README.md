# MongoDB – Historial Técnico Vehicular

## Descripción
Implementación de MongoDB Atlas como base de datos NoSQL para almacenar el historial técnico de los vehículos del sistema de taller automotriz.

## Tecnologías utilizadas
- MongoDB Atlas
- Go
- MongoDB Go Driver
- API REST
- MySQL

## Funcionalidades
- Conexión del backend con MongoDB Atlas.
- Registro de eventos de mantenimiento vehicular.
- Almacenamiento de información técnica de los vehículos.
- Consulta del historial mediante endpoints de la API.
- Creación de índices para optimizar las consultas.

## Evidencias
Se incluyen capturas de la conexión, colección, documentos almacenados, índices, código backend y pruebas de la API.

## Integración
MongoDB se utiliza para la persistencia del historial técnico vehicular, mientras que MySQL mantiene la información relacional del sistema.
